# Phase 9 Validation & Analysis Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `notebooks/complexity_analysis.ipynb` (generated reproducibly by `scripts/generate_complexity_analysis_notebook.py`, following the exact convention `scripts/generate_score_design_notebook.py` established in Phase 7) — the authoritative validation notebook for `complexity_index_v1.csv`, covering distribution, batch/status/industry breakdowns, a full correlation heatmap, a fresh team-size correlation check, targeted validation questions, and a fresh manual outlier review, per `docs/superpowers/specs/2026-07-13-phase9-validation-analysis-design.md`.

**Architecture:** A pure-analysis notebook (no new `src/` module — nothing here feeds a downstream pipeline step). The generator script builds a `CELLS` list of `markdown_cell()`/`code_cell()` dicts and writes `notebooks/complexity_analysis.ipynb` as plain JSON (`nbformat` 4.5), then the notebook is executed via `jupyter nbconvert --execute --inplace` to produce real outputs. Each task appends new cells to the end of `CELLS`, regenerates, re-executes, and inspects the real output before moving on — the notebook equivalent of TDD's "write, run, verify" cycle.

**Tech Stack:** Python stdlib (`json`, `pathlib`) + `pandas`, `numpy`, `matplotlib` (all already dependencies) + `jupyter`/`nbconvert` (already dependencies, used identically to Phase 7).

## Global Constraints

- Analyze only — no changes to `src/etl/score.py`'s weights/caps/formula in this plan. If the fresh Phase 9 numbers confirm the Phase 7 calibration gap (team-size correlation, distribution spread), that is recorded as a finding; fixing it is an explicit follow-up brainstorming pass with its own spec, out of scope here (spec Decision 1).
- Team-size correlation and manual outlier review are re-derived fresh in this notebook, not copied from `notebooks/score_design.ipynb` (spec Decision 2). `complexity_analysis.ipynb` must be self-contained.
- Industry breakdown explodes on industry: a company with multiple industry tags contributes its `complexity_score` to every tagged industry's group (spec Decision 3). No "primary industry" simplification.
- No new `src/` module or reusable functions — everything lives in the notebook (spec Decision 4).
- Acceptance bar: `jupyter nbconvert --execute --inplace` must exit 0 with no exceptions, and each code cell must show real output (spec Decision 5) — this replaces unit tests as the verification mechanism, since there's no reusable logic to unit-test.
- Industry bar chart is filtered to industries with **≥20 tagged companies** (spec Decision 6) to avoid noisy single-company averages.
- Batches are sorted chronologically (Winter before Summer within the same year: `W06, S06, W07, S07, ...`), not alphabetically, for the by-batch breakdown.
- Regenerate the notebook by re-running the generator script, never by hand-editing the `.ipynb` — same convention as `scripts/generate_score_design_notebook.py`.

- [ ] **Step 1: Write the generator script**

Create `scripts/generate_complexity_analysis_notebook.py`:

```python
"""
Generates notebooks/complexity_analysis.ipynb for Phase 9 validation & analysis.

Run: ./.venv/Scripts/python.exe scripts/generate_complexity_analysis_notebook.py

Regenerate this way (not by hand-editing the .ipynb) whenever a cell needs
to change, so the notebook stays reproducible from source.
"""

import json
from pathlib import Path

REPO_ROOT = Path(__file__).resolve().parents[1]
OUTPUT_PATH = REPO_ROOT / "notebooks" / "complexity_analysis.ipynb"


def markdown_cell(text: str) -> dict:
    return {
        "cell_type": "markdown",
        "metadata": {},
        "source": text.splitlines(keepends=True),
    }


def code_cell(text: str) -> dict:
    return {
        "cell_type": "code",
        "execution_count": None,
        "metadata": {},
        "outputs": [],
        "source": text.splitlines(keepends=True),
    }


CELLS = [
    markdown_cell(
        "# Phase 9 Validation & Analysis\n"
        "\n"
        "Authoritative validation notebook for `data/processed/scores/complexity_index_v1.csv` "
        "(self-contained — re-derives team-size correlation and manual outlier review fresh "
        "rather than citing `notebooks/score_design.ipynb`). Covers score distribution, "
        "technical-vs-practical relationship, complexity by batch/status/industry, a full "
        "correlation heatmap, team-size correlation, targeted validation questions, manual "
        "outlier review, and findings, per "
        "`docs/superpowers/specs/2026-07-13-phase9-validation-analysis-design.md`."
    ),
    code_cell(
        "import sys\n"
        "from pathlib import Path\n"
        "\n"
        "import numpy as np\n"
        "import pandas as pd\n"
        "\n"
        "REPO_ROOT = Path.cwd().parent if Path.cwd().name == \"notebooks\" else Path.cwd()\n"
        "sys.path.insert(0, str(REPO_ROOT))\n"
        "\n"
        "scores_df = pd.read_csv(REPO_ROOT / \"data\" / \"processed\" / \"scores\" / \"complexity_index_v1.csv\")\n"
        "features_df = pd.read_parquet(REPO_ROOT / \"data\" / \"processed\" / \"features\" / \"complexity_features.parquet\")\n"
        "companies_df = pd.read_csv(REPO_ROOT / \"data\" / \"processed\" / \"step3_enriched\" / \"companies_enriched.csv\")\n"
        "industries_df = pd.read_csv(REPO_ROOT / \"data\" / \"processed\" / \"step3_enriched\" / \"industries_enriched.csv\")\n"
        "\n"
        "merged = scores_df.merge(companies_df[[\"id\", \"teamSize\"]], on=\"id\", how=\"left\")\n"
        "merged[\"log_team_size\"] = np.log1p(merged[\"teamSize\"])\n"
        "\n"
        "feature_cols = [c for c in features_df.columns if c not in (\"id\", \"slug\", \"name\", \"batch\", \"status\")]\n"
        "merged = merged.merge(features_df[[\"id\"] + feature_cols], on=\"id\", how=\"left\")\n"
        "\n"
        "industry_merged = scores_df.merge(industries_df, on=\"id\", how=\"left\")\n"
        "\n"
        "merged.shape, industry_merged.shape"
    ),
]


def build_notebook() -> dict:
    return {
        "cells": CELLS,
        "metadata": {
            "kernelspec": {"display_name": "Python 3", "language": "python", "name": "python3"},
            "language_info": {"name": "python"},
        },
        "nbformat": 4,
        "nbformat_minor": 5,
    }


def main() -> None:
    OUTPUT_PATH.parent.mkdir(parents=True, exist_ok=True)
    with open(OUTPUT_PATH, "w", encoding="utf-8") as f:
        json.dump(build_notebook(), f, indent=1)
    print(f"Wrote {OUTPUT_PATH}")


if __name__ == "__main__":
    main()
```
