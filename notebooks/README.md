# Notebooks Directory

This directory contains Jupyter notebooks for exploratory data analysis and visualization.

## Recommended Notebook Structure

1. **01_data_exploration.ipynb**: Initial data exploration and statistics
2. **02_data_cleaning.ipynb**: Data cleaning and preprocessing steps
3. **03_analysis.ipynb**: Main analysis and insights
4. **04_visualization.ipynb**: Creating charts and visualizations

## Best Practices

- Use descriptive names with number prefixes for ordering
- Document your analysis with markdown cells
- Clear all outputs before committing (unless they're important)
- Keep notebooks focused on specific tasks
- Import reusable code from the `src/` directory
